# Segurança

## Reportar Vulnerabilidades

Se você descobrir uma vulnerabilidade de segurança neste repositório, **não abra uma issue pública**.

Utilize os canais institucionais oficiais do Sertão Digital para reportar problemas de segurança de forma responsável.

## Práticas de Segurança

Este repositório é **público**. Nunca commit:

- Tokens de autenticação
- Senhas ou passphrases
- Chaves privadas
- Credenciais de API
- Dados pessoais (PII)
- Informações sensíveis de configuração
- Secrets ou credentials de qualquer tipo

Use `.gitignore` para proteger arquivos locais sensíveis.

## Validação Automática

Este repositório inclui validação automática para detectar padrões comuns de segredos. No entanto, **você é responsável** por revisar seu código antes de fazer commit.

## Segurança de Dependências

Ao adicionar dependências externas, considere:

- Licença e compatibilidade
- Manutenção ativa
- Reputação e confiabilidade da fonte
- Impacto na segurança

## Mais Informações

Para questões de segurança mais detalhadas, consulte a documentação de segurança do Sertão Digital nos canais oficiais institucionais.
