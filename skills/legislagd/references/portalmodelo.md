# PortalModelo-SD

Portal Institucional e Interface Pública de LegislaGD.

## Informações Rápidas

| Campo | Valor |
|---|---|
| **Nome Completo** | PortalModelo-SD |
| **Função** | Portal institucional legislativo |
| **Upstream** | PortalModelo (verifique) |
| **Acesso** | Público (sem login obrigatório) |

## Responsabilidades

- ✅ Interface web pública
- ✅ Consulta de proposições
- ✅ Publicação de sessões
- ✅ Informações institucionais
- ✅ Responsividade mobile

## Conteúdo Públicado

- Proposições em andamento
- Sessões realizadas (atas)
- Votações (resultados públicos)
- Parlamentares (dados públicos)
- Eventos legislativos

## Integra com

- SAPL-SD (fonte de dados legislativos)
- Keycloak (autenticação opcional)
- SIGI-SD (protocolo para cidadão)

## Tecnologias

- Frontend: JavaScript/React (verificar)
- Backend: Node.js ou Python (verificar)
- Containerização: Docker

## Repositório

Será registrado em `repositories.yaml`.

## Importante

- Não contém dados restritos
- Atualizações em tempo real preferível
- Performance: cache de dados públicos
