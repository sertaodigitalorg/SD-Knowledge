# SIGI-SD

Sistema de Gestão de Políticas Internas - Versão Sertão Digital.

Atendimento ao cidadão e protocolo para LegislaGD.

## Informações Rápidas

| Campo | Valor |
|---|---|
| **Nome Completo** | SIGI-SD |
| **Função** | Atendimento ao cidadão + Protocolo |
| **Plataforma** | Omnichannel (web, chat, email) |
| **Integração** | Chatwoot (possível) |

## Responsabilidades

- ✅ Protocolo de atendimento ao cidadão
- ✅ Roteamento de demandas
- ✅ IA de classificação/atenção
- ✅ Omnichannel (web, chat, email)
- ✅ Integração com proposição (elo)

## Tipos de Atendimento

- Dúvida sobre proposição (→ SAPL)
- Solicitação de informação
- Reclamação/sugestão
- Requerimento de serviço
- Acesso à informação

## Integra com

- SAPL-SD (link protocolo ↔ proposição)
- Chatwoot (omnichannel, se utilizado)
- IA (classificação automática)
- Keycloak (autenticação de cidadão)
- Notificação (email, SMS, push)

## Tecnologias

- Backend: Verificar repositório
- Frontend: Verificar repositório
- Chatwoot: Integração com API REST
- IA: LLM local ou cloud (a definir)

## Repositório

Consulte `repositories.yaml` para a URL canônica e o status validado do repositório.
## LGPD Compliance

- Consentimento de cidadão
- Retenção limitada de dados
- Anonimização de atendimento
- Direito ao esquecimento (após prazo)
- Política de privacidade clara
