# Organização Sertão Digital

## Estrutura

Sertão Digital é um Centro de Inovação e Tecnologia focado em:

- Transformação digital de instituições públicas
- Desenvolvimento de software livre
- Pesquisa em inovação tecnológica
- Capacitação em tecnologia
- Interoperabilidade entre sistemas

## Repositórios Principais

Veja `repositories.yaml` para lista completa.

Alguns repositórios principais:

- **LegislaGD** — Plataforma legislativa livre (Poder Legislativo)
- **SAPL-SD** — Sistema de Acompanhamento de Processo Legislativo
- **e-Cidade-SD** — ERP municipal/legislativo
- **SIGI-SD** — Sistema de Inteligência Geral de Interações
- **PortalModelo-SD** — Portal institucional
- **VEREDAS** — Sistema de participação cidadã
- **Plataforma360** — Plataforma de gestão integrada
- **Notícia Sertaneja** — Portal de notícias
- **Roteiro Comercial** — Plataforma comercial

## Governança

Veja `governance.yaml` para políticas de decisão.

Pontos principais:

- Decisões estratégicas em Google Drive (assinadas)
- Decisões técnicas em GitHub (PRs e code review)
- Skills documentam regras de contexto
- Manifestos registram estado atual
- Versionamento semântico
