# Decisão sobre Licença

## Contexto

Este repositório é público e será o master técnico para a SDKA (Arquitetura de Conhecimento e Skills) do Sertão Digital.

Contém:
- Documentação arquitetural
- Skills e definições de conhecimento
- Schemas de validação
- Exemplos
- Workflows

## Opções Consideradas

### 1. Apache License 2.0

**Pros:**
- Amplamente reconhecida para software
- Inclui proteção de patentes
- Compatível com muitos projetos
- Boa para documentação técnica

**Cons:**
- Pode ser excessiva para documentação pura

### 2. MIT License

**Pros:**
- Simples e permissiva
- Amplamente adotada
- Fácil de entender

**Cons:**
- Sem proteção de patentes
- Menos apropriada para documentação formal

### 3. Creative Commons BY 4.0

**Pros:**
- Apropriada para documentação e conhecimento
- Requer atribuição
- Clara para conteúdo não-código

**Cons:**
- Menos apropriada para schemas e exemplos de código
- Restrições para uso comercial podem ser problemáticas

### 4. Dual License (Apache 2.0 + CC BY 4.0)

**Pros:**
- Código sob Apache
- Documentação sob CC BY
- Flexibilidade máxima
- Clareza para reutilização

**Cons:**
- Mais complexo
- Requer comunicação clara

## Status Atual

**DECISÃO PENDENTE**

Aguardando decisão institucional do Sertão Digital sobre qual modelo de licença melhor se alinha com:
- Política de software livre
- Estratégia de compartilhamento de conhecimento
- Compatibilidade com ecossistema de projetos

## Recomendação Provisória

Recomenda-se **Dual License** (Apache 2.0 + CC BY 4.0) para máxima flexibilidade:
- Código e schemas: Apache 2.0
- Documentação: CC BY 4.0
